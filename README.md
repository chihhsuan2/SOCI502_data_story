## SOCI502 Data Story: Unemployment of Tertiary-Educated Immigrant Women in OECD Countries
### Overview

This project explores whether tertiary education reduces the labour market disadvantage faced by foreign-born women. Using OECD data, it compares the unemployment rates of foreign-born and native-born tertiary-educated women across OECD and partner countries in 2023, and examines how the gap varies by country, region, age group and level of educational attainment.

This is a course project for SOCI 502 at the University of British Columbia.

### Data

The data come from the OECD Data Explorer (Education at a Glance database), dataset DSD_EAG_LSO_EA@DF_LSO_NEAC_UNEMP_MIGR.
